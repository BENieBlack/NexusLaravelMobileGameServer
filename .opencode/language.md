# 言語設定 / Language Configuration

## 日本語で応答してください

このプロジェクトでは、**日本語**でコミュニケーションを行ってください。

### 基本ルール

- すべての応答は日本語で行う
- コードコメントは日本語で記述する
- コミットメッセージは日本語で記述する
- ドキュメントは日本語で記述する
- エラーメッセージの説明は日本語で行う

### 例外

以下の場合は英語を使用してください：

- コード内の変数名、関数名、クラス名（英語のみ）
- Git コミットメッセージのプレフィックス（`feat:`, `fix:`, `refactor:` など）
- 技術的な専門用語（必要に応じて日本語の説明を追加）
- 外部ライブラリやフレームワークの名称

---

## Please Respond in Japanese

For this project, please communicate in **Japanese**.

### Basic Rules

- All responses should be in Japanese
- Code comments should be written in Japanese
- Commit messages should be in Japanese
- Documentation should be in Japanese
- Error message explanations should be in Japanese

### Exceptions

Use English in the following cases:

- Variable names, function names, class names in code (English only)
- Git commit message prefixes (`feat:`, `fix:`, `refactor:`, etc.)
- Technical terminology (with Japanese explanations when necessary)
- External library and framework names
